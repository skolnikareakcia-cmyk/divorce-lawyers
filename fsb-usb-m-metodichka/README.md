# Методичка УСБ-М: оперативный эксперимент и задержание

RP-документ для фракции ФСБ сервера «Арбатский» проекта «Россия Онлайн» (GTA 5 RP).
Юридической силы не имеет.

- `Metodichka_USB-M.pdf` — для чтения и печати.
- `Metodichka_USB-M.docx` — для правки: поля для заполнения выделены синим курсивом в квадратных скобках.
- `src/` — исходники: `generate.js` (текст и вёрстка), `schema.py` (схема расстановки ГЗ), `build.py` (сборка docx → pdf и номера страниц в содержании).

Пересборка: `cd src && npm install && python3 build.py` (нужны Node.js, LibreOffice с Writer и poppler-utils).
